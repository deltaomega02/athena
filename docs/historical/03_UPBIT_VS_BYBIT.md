# 03. 업비트 vs Bybit 구조 차이

## 핵심 비교

| 요소 | Bybit (HERMES) | 업비트 (UPBIT_BOT) |
|---|---|---|
| 거래 유형 | 무기한 선물 | **현물만** |
| 마켓 통화 | USDT | **KRW** (원화) |
| 레버리지 | 최대 100x (HERMES 7x) | **없음 (1x)** |
| 진입 방향 | LONG + SHORT | **LONG만** (현물은 살 수만) |
| 수수료 | taker 0.055% / maker 0.020% | **0.05% (maker/taker 동일)** |
| 펀딩비 | 8h마다 정산 | **없음** |
| 상장 코인 | 400+ | 한국 마켓 200+ |
| 김치 프리미엄 | 없음 | **5~10% 존재 (2021년까지, 현재 봉쇄)** |
| API 제한 | 초당 10req | 초당 8~10req |
| 세금 | 2027년부터 22% | **동일 (2027년 22%)** |

## UPBIT_BOT 핵심 제약

### 1. SHORT 불가 → 전략 반쪽 포기
- HERMES는 V12에서 SHORT 3승 8패 (27%)지만 일부 수익 기여
- 업비트 현물은 하락장에 **그냥 기다리거나 원화 보유**만 가능
- 하락 사이클에서 자금 놀게 됨

### 2. 레버리지 없음 → 자본 효율 낮음
- ₩100만 = $680 정도 (1x)
- HERMES 7x 대비 수익 잠재력 1/7
- 연 수익률 목표 자연스럽게 낮음

### 3. 김치 프리미엄 변수
- 2017~2021년: 차익 가능 (1~10% 스프레드)
- 2022~ 트래블룰 후: 사실상 봉쇄
- 2025년 8월~: 마이너스 디스카운트 전환
- **현재 김프 차익은 비추**

### 4. 펀딩비 차익 X
- 업비트는 펀딩 없음 = 펀딩 차익 전략 불가
- 단 단순화 측면에서 OK

## 수수료 구조 비교

### Bybit (HERMES)
```
Maker:  0.020% (PostOnly limit)
Taker:  0.055% (market)

V13.1 Hybrid 사용 시:
  진입(maker 가능) + 청산(taker 강제) = 0.075% 왕복
```

### 업비트 (UPBIT_BOT)
```
모든 주문:  0.050% (maker/taker 동일)

왕복:  0.10% (HERMES 0.075%보다 약간 비쌈)

VIP/이벤트:  거래량 따라 일부 할인 가능
```

**Note**: 업비트가 maker 우대 없어서 PostOnly 의미 적음. 단순 limit 사용.

## 🇰🇷 한국 시장 특화 요소

### 활용 가능한 차이
1. **원화 직접**: USDT 환전 손실 없음
2. **24시간 거래**: HERMES와 동일
3. **한국 사용자 행동 패턴**: 김치 프리미엄 사이클, 알트 펌프 등

### 활용 어려운 차이
1. **원화 입출금 제한**: 트래블룰 (₩1000만/연)
2. **KYC 강도**: Bybit보다 엄격
3. **상장/상폐**: 한국 거래소 정치적 영향
4. **주말 거래량**: 평일 대비 ↓

## 업비트 전략에 적합한 것

### 적합
- **DCA (Dollar Cost Averaging)**: 정기 매수, 단순
- **Long-Only HERMES 변형**: TRENDING_UP만 진입
- **GRID 봇 (현물)**: 박스권 분할 매매 (청산 위험 X)
- **돌파 매수**: 강한 상승 모멘텀 진입

### 부적합
- ~~Short 전략~~ (현물은 불가)
- ~~펀딩 차익~~ (펀딩 없음)
- ~~델타 중립~~ (헤지 수단 없음)
- ~~김프 차익~~ (현재 봉쇄)

## 학술/실증 데이터 (참고)

### 한국 자동매매 통계 (HERMES 메모리)
- 1년+ 흑자 비율: **1~3%**
- 시드 ₩80~200만 6개월 후: 보존 20~30%, 흑자 5~10%, 50%+ 손실 60%+
- 실패 패턴 1위: "상승장 수익 → 자만 → 시드 증액 → 첫 조정에서 전액"

### Pionex Grid 봇 후기 (실증)
- 횡보장: 일 0.05~0.2% 수익 가능
- 추세장 시작: 그리드 트랩, 큰 손실
- 일관 수익자 ~5%

### DCA 학술 결과
- 4년 BTC 단순 DCA: 시중 자동매매 봇 80% 이김
- 단순함의 강점
