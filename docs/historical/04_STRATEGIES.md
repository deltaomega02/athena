# 04. 전략 옵션

## 5가지 후보 전략 (정직 평가)

### 옵션 A: 단순 DCA (Dollar Cost Averaging) ⭐ 가장 단순
**작동**: 매주/매월 정해진 금액으로 BTC/ETH 매수

```
예: 매주 월요일 09:00 ₩50,000 BTC 자동 매수
    ₩100만 / 20주 = 5개월 분할
```

**장점**:
- 구현 매우 단순
- 학술적 검증 (4년 누적 시중 봇 80% 이김)
- 시장 타이밍 X
- 감독 부담 최소

**단점**:
- "자동매매"라는 느낌 약함
- 단기 수익 X (장기 적립 성격)
- 베어 사이클에 잔액 묶임

**예상 수익**: 시장 추세 따라감 (1년 -20%~+50%)

**난이도**: ⭐

---

### 옵션 B: Long-Only HERMES 변형 ⭐⭐ HERMES 코드 재활용
**작동**: HERMES TREND_PULLBACK 그대로 + LONG only + 레버리지 X

```
4H 레짐 = TRENDING_UP  →  EMA 풀백 시 BTC/ETH 매수
4H 레짐 = TRENDING_DOWN/RANGING/HIGH_VOL  →  현금 대기
SL/TP는 HERMES 그대로
```

**장점**:
- HERMES 코드 재활용 (개발 빠름)
- 검증된 로직 (4H+1H+1D 다중 시간대)
- 풀백 진입 = 슬립 적음

**단점**:
- 하락장에 자금 놀음 (TRENDING_UP만 진입)
- HERMES 베어 사이클 약점 동일
- 레버리지 없어 수익률 1/7

**예상 수익**: HERMES 평균의 절반~1/3 수준

**난이도**: ⭐⭐

---

### 옵션 C: Grid 봇 (현물) ⭐⭐⭐ 현재 시장 적합
**작동**: 박스권 자동 분할 매수/매도

```
예: BTC ₩100,000,000 ~ ₩110,000,000 (10등분)
    ₩100M에 매수 → ₩101M에 매도 (₩1M 수익)
    ₩102M에 매수 → ₩103M에 매도 ...
```

**장점**:
- 현재 시장 (베어+저변동) 환경 매칭
- 횡보장에 작은 수익 누적
- 현물이라 청산 위험 X
- Pionex/3Commas 검증

**단점**:
- 추세장 시작 시 트랩 (상단 그리드 매수 후 하락)
- 박스권 설정 핵심 (잘못 설정 시 큰 손실)
- 잦은 거래로 수수료 ↑

**예상 수익**: 횡보장 일 0.05~0.2% / 추세장 -10~-30%

**난이도**: ⭐⭐⭐

---

### 옵션 D: 하이브리드 (DCA + Long-Only HERMES) ⭐⭐⭐⭐
**작동**: 시드 분할 운영
```
시드 ₩100만 분배:
  ₩50만: 단순 DCA (매주 ₩25,000 BTC + ETH)
  ₩50만: Long-Only HERMES (TRENDING_UP만)
```

**장점**:
- 환경 분산 (DCA는 항상, HERMES는 추세장만)
- 시드 보존 우선
- 환경별 자동 적응

**단점**:
- 두 시스템 운영 = 복잡도 ↑
- 자금 파편화 = 효율 ↓

**예상 수익**: B와 A의 가중 평균

**난이도**: ⭐⭐⭐⭐

---

### 옵션 E: 김프 차익 (역사적, 현재 비추) ⭐⭐⭐⭐⭐
**작동**: Bybit-업비트 가격 차이 활용 (델타 중립)

**장점**:
- 시장 방향 무관 (이론적으로 안정적)
- 학술 검증

**단점**:
- 2025년 8월~ 마이너스 디스카운트 (역방향 김프)
- 트래블룰로 자금 이동 제한 (₩1000만/연)
- ₩100만 시드 너무 작아 의미 없음
- 양 거래소 KYC + 수수료 + 슬리피지

**예상 수익**: 현재 환경 거의 0 (2017~2021 시기 환상)

**난이도**: ⭐⭐⭐⭐⭐ (현재 거의 불가능)

## 권장 순위 (정직)

### 1위: **옵션 A (단순 DCA)** — 가장 합리
**이유**:
- 운영자 "자동매매로 자본 증대" 의지 충족 (자동 매수)
- HERMES 본업 = 적극 매매. UPBIT_BOT은 **단순 적립**으로 차별화
- 학술 검증 (4년 시중 봇 80% 이김)
- 즉시 가동 가능

### 2위: 옵션 D (하이브리드)
**이유**: A의 안전성 + B의 적극성 조합. 단 복잡도 ↑

### 3위: 옵션 B (Long-Only HERMES)
**이유**: 검증된 로직. 단 하락장에 자금 놀음

### 4위: 옵션 C (Grid)
**이유**: 매력적이지만 박스권 결정 어려움 + 추세 시작 시 큰 손실 위험

### 최후위: 옵션 E (김프)
**이유**: 현재 환경 작동 X

## 내 솔직 권장

### **옵션 A로 시작 → 데이터 보고 옵션 B 추가 검토**

근거:
1. **시드 ₩100만은 단순 전략이 효율적** (수수료/복잡도 비율)
2. **HERMES 운영 부담** 감소 (UPBIT_BOT은 일주일에 한 번 체크)
3. **학술 + 실증 검증** (DCA의 강점)
4. **확장 여지**: 시드 증액 시 옵션 D로 진화 가능

### 구체 DCA 구조 (예시)
```
매주 월요일 09:00 KST:
  - BTC ₩30,000 매수
  - ETH ₩20,000 매수
  
시드 ₩100만 / 주 ₩50,000 = 20주 (약 5개월) 분할

총 거래: 100건/년 (20주 × 5코인)
수수료: ₩100만 × 0.05% × 100 = ₩50,000/년 (시드 5%)
```

### 발전 옵션
데이터 기반 결정:
- 시장이 베어 → DCA 계속 (저점 매수)
- 시장이 강세 → 옵션 B (HERMES Long-Only) 추가
- 시장이 횡보 → 옵션 C (Grid) 검토
