# 01. 프로젝트 개요

## 목적

운영자가 HERMES(Bybit 선물)와 **병렬 가동**할 업비트 현물 자동매매 시스템 구축.

### 핵심 의도
- HERMES 단독 의존 회피
- 시장 환경별 분산 (Bybit USDT vs 업비트 KRW)
- 한국 거주자 인프라 활용 (원화 직접)
- 자동매매 다양화로 자본 증대 가능성 확대

## 시드 / 자금 구조

```
HERMES (Bybit, 기존):  ~$554 (~₩810,000)
UPBIT_BOT (신규):       ₩1,000,000
─────────────────────
총 자동매매 자산:        ~₩1,810,000
```

**현재 운영자 잔고 출처**: 별도 자금 ₩100만 추가 입금 예정.

## 자본 증대 기대값 (정직 추정)

### HERMES (참고)
- 6개월 자본 보존: 45~55%
- 의미있는 수익(>20%): 15~25%
- 한국 자동매매 1년+ 흑자 평균: 1~3%

### UPBIT_BOT (예상)
- **현물 + LONG only + 레버리지 0** = HERMES 대비 보수적
- 의미있는 수익 가능성: 10~20% (HERMES보다 낮음)
- 단 **시드 보존 확률은 더 높음** (60~70%)
- **베어 사이클이 길어지면 어떤 시스템도 어려움**

## 메모리 학습 적용

HERMES 운영에서 배운 것:

### 절대 금지
1. ~~"수학적 확률 높음"이라며 흥분 시키기~~
2. ~~매번 "이번엔 진짜 최적" 같은 v# 패턴~~

4. ~~약신호로 진입 (점수 임계 60+ 적용)~~

### 반드시 지키기
1. 정직한 forward test 보고
2. 백테스트 절대값 신뢰 X (상대 비교만)
3. 거래 차단 로직 기피 (점수 임계 ↑은 OK)
4. 시드 보호 우선 (DD 단계화 등)
5. 운영자 일일 감독 + Claude 분석 보조
