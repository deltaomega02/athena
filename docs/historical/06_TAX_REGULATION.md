```
  세금: ₩7,500,000 × 22% = ₩1,650,000

```

## 2026년 활용 전략 (메모리 학습)

### 취득가 리셋 혜택
**2027년 1월 1일 이전 보유** 가상자산은 **2026년 12월 31일 종가** 기준으로 취득가 인식.

즉:
```
2024년 ₩50M에 BTC 매수
2026-12-31 BTC 가격 ₩100M (가정)
2027-01-01 시점 취득가 = ₩100M로 리셋

2027년 ₩120M에 매도 시:
  과세 대상: ₩120M - ₩100M = ₩20M
  ₩50M 시점부터 누적된 ₩70M 차익은 비과세
```

→ **2026년 말까지 매수한 자산은 2026-12-31 시가 기준으로 취득가 인식 = 그 이전 차익 비과세**.

### 액션 아이템
1. **2026-12-31 시점 잔고/시가 정확히 기록** (취득가 리셋용)
2. **2027-01-01 이후 매매**는 과세 대상이므로 정직하게 신고
3. **연 250만 공제** 활용해 작은 매매는 세금 X

## HERMES vs UPBIT_BOT 세금 비교

### HERMES (Bybit, USDT)
- 해외 거래소 = **국세청 자진 신고**
- 2027년~ 같은 22% 과세
- USDT/USD 환율 영향 (원화 환산 시)

### UPBIT_BOT (한국 거래소)
- 국내 거래소 = **거래소 자동 신고** (지급조서)
- 한국 국세청 직접 추적 가능
- 원화 직접이라 환율 영향 X

### 결론
**UPBIT_BOT은 세금 측면에서 더 투명/정직**. HERMES도 자진 신고 필요.
